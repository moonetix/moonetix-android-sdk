# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [2.0.1] - 2026-11-11

### Changed

- Only pages on `wall.moonetix.com` stay inside the offerwall screen. Every other host, including former wall hosts, opens outside the app.
- The top bar logo loads only from `moonetix.com` and `wall.moonetix.com`.

## [2.0.0] - 2026-11-06

### Changed

- First release under the Moonetix name. The previous package stays published and keeps working.
- Maven coordinates `com.moonetix:offerwall:2.0.0` from https://moonetix.com/maven, package `com.moonetix.offerwall`, class `Moonetix`, types `MoonetixOptions`, `MoonetixListener` and `MoonetixError`.
- The offerwall opens on `wall.moonetix.com`.
